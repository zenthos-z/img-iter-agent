# 重构计划 v4（完整版）：Critic 驱动的经验闭环 + 一题一 loop + sample 层级 + 多策略基建

> 已删除历史 loop。所有改动在干净 state 上进行。

## 核心诊断
经验是"事实记录"非"闭环验证"，因：①信息流在 summarizer 被截断成单帧（只看本轮）；②经验散落为单轮 MD 碎片，无沉淀层。Critic 是"改动有效性"的唯一客观裁判，其 verdict（分+失败项+**理由 reason**）是闭环验证的核心证据。

---

## Critic 驱动的闭环（三角色）
```
轮次 N:
  1. Generator 改 prompt（产出 delta_note）→ 出图
  2. Critic 看图 → verdict_N（分 + 失败项✗ + reason 理由）  ← 客观裁判
轮次 N+1:
  3. Summarizer 综合【上轮 delta_note + 上轮 verdict_{N-1} + 本轮 verdict_N】:
     对比 Critic 前后判定 → 判 status(effective/ineffective) → 沉淀进 conclusions.json
  4. Generator 读 conclusions（effective 保留约束 / ineffective 换思路）
```

## 经验知识库设计（结构化 JSON + 归属 sample）
载体：`data/runs/<loop_id>/lessons/conclusions.json`（废弃散落单轮 MD）。
每条结论：`{id, dim, finding, change, status(pending/verified_effective/ineffective), critic_evidence{tested_round, before{value,failed,reason}, after{...}, verdict_delta}, lesson, tags, created_round, verified_round}`。
status 由 Critic 前后 verdict 驱动判定。
