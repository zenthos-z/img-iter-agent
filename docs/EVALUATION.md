## 2. 打分机制（量化版）

```
单张生成图
   │
   ▼
Critic 对每个维度独立打 0–10 分：  material=8.5, color=7.0, structure=8.0, ...
   │
   ▼
还原度总分 = Σ(维度分 × 权重 wᵢ)   例如 8.5×.22 + 7.0×.15 + ... = 7.7
   │
   ▼
人工审批（看总分 + 图）
```

## 3. 问题诊断：为什么量化打分站不住

| 问题 | 表现 | 根因 |
|------|------|------|
| **LLM 不擅长回归** | 同一张图，material 多次打分可能 7 / 8 / 8.5 漂移 | LLM 本质是分类器，"给材质打 8.5 分"是回归任务，无客观锚点 |
| **不可复现** | 跨模型/跨时间/跨温度，分数不一致 | 量化分数无稳定基准，每次推理都是新的"猜分" |
| **维度模糊** | "材质 8.5"到底扣在哪？说不清 | 一个数字压缩了多个子问题，归因丢失 |
| **校准闭环建在沙上** | §2.6 用人工分回归权重，但人工分本身也是猜的量化 | 量化 × 量化 = 误差叠加 |

> **核心洞察（用户）**：大模型擅长**分类**（是/否、对/错、有/无），不擅长**量化**（打几分）。
> 所以应把每个"维度"拆成一组**二分判定（✓/✗）**，让 Critic 做 it 擅长的事。

## 4. 新机制：混合评分（二分 + 连续）+ 排序校准

> 用户的关键修正（2026-07-30）：**不是所有维度都能二分**。结构/瑕疵/一致性是客观 ✓/✗，
> 但材质还原度、颜色准确度是**渐变**的，"还原 80% 还是 90%"有意义——这些只能让 LLM
> 打连续分（承认它有偏差、不稳）。校准不靠"人工逐项打分"（人也猜不准），
> 而靠**人工对 trace 排序**（人的强项），拟合权重让"加权总分排序"吻合人类排序。
> 这个拟合**天然修正 LLM 连续打分的系统性偏差**。

### 4.1 维度分两种评分类型

| 维度类型 | 评法 | 哪些维度 | 为什么 |
|----------|------|----------|--------|
| **二分型** | 逐项 ✓/✗ → 维度通过率 | 一致性 / 结构 / 瑕疵 / 商业 | 客观可判、稳定、归因清晰 |
| **连续型** | LLM 打 0–1 连续分 | 材质还原度 / 颜色准确度 | 渐变量，二分会丢信息；承认 LLM 有偏差 |

每个维度产出一个 `[0,1]` 的分（二分型=通过率，连续型=归一化分），形式统一。

### 4.3 评分机制（混合版）

```
每个 trace → 特征向量 features = [一致性, 结构, 材质, 颜色, 瑕疵, 商业]  各∈[0,1]
   二分型维度: features[i] = checklist 通过项数/总项数
   连续型维度: features[i] = LLM 归一化分(0-1)

还原度总分 = Σ(wᵢ × features[i])     ← 权重 w 由排序校准学出
```

- **一套考题（多个家具）统一可比**：每个 trace 一个还原度分，横向对比不同 trace 的迭代效果直观。
- 二分型维度稳定可靠；连续型维度有 LLM 偏差，但被排序校准的权重吸收。

### 4.4 排序校准：为什么用排序而不是逐项打分（核心洞察）

- **人猜不准"材质 72 分"**，但**人能可靠判断"trace A 比 trace B 好"**——排序是人类的强项。
- 校准目标：找权重 w，使 `w·features` 的排序**尽量吻合**人类排序（learning-to-rank）。
- **天然修正偏差**：若 LLM 把材质分系统性打高，校准时材质维度权重被压低，
  最终排序仍贴合人类——LLM 的连续分偏差被"自动校准掉"，无需逐项修。
- 校准还能发现：哪个维度对人类排序影响最大（真实重要性）→ 调该维度权重 / 加扣分项。

### 4.5 对校准闭环的影响（最干净的形态）

| 旧(全量化) | 我之前过度(全二分) | **现在(混合+排序)** |
|-----------|------------------|---------------------|
| 人工逐项打分 vs LLM逐项分 → 回归权重 | 人工逐项✓/✗ vs LLM逐项✓/✗ → 一致率 | **人工排序 → 学w拟合排序** |
| 量化×量化，误差叠加 | 渐变维度丢信息 | **各取所长，排序修正连续分偏差** |
| 人难做 | 渐变维度人难判 | **人只做擅长的排序** |

## 5. 任务：三视图白底素材（视角已定）

**任务**：从参考图生成家具**工业标准三视图**白底素材图。

视角（用户确认）：**正视图（正面平视） + 侧视图（90°侧面平视） + 立体图（45°斜侧）**。

为什么三视图适合这套评测：
- **交付物明确**：3 张具体视图，"是否生成 3 视角""是否同产品"是强二分项；
- **跨视图一致性**是核心质量信号（量化难评、二分好评、占高权重 0.25）；
- **几何可验**：侧视宽=正视宽、各视图高度比例一致——客观可判，支撑二分；
- **商业价值**：直接对应电商详情页多视角素材需求。
