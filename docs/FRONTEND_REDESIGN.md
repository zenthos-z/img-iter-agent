# img-iter-agent 打分台前端 Redesign 方案

## 当前问题诊断

1. **信息架构扁平、导航弱**
   - 只有顶部两链接（总览 / Agent 设置），loop 详情、排序页都靠卡片点击进入，层级不清。
   - 用户在总览页里同时面对「bench 标题 → sample 行 → loop 卡片」三层嵌套，视觉疲劳。

2. **交互状态反馈粗糙**
   - 运行中/等审批状态只靠小圆点和轮询文字，缺少进度骨架与明确操作区。
   - 错误信息用 `<details>` 折叠，显眼度不足；成功/失败用 `alert()`，阻断体验。

3. **内容密度不均、卡片含义混乱**
   - loop 卡片与 trace 卡片样式相同，但承载的层级不同。
   - trace 详情塞进 modal，图片、critic 评分、prompt、经验沉淀挤在一起，难以扫描。

4. **排序页体验单薄**
   - 拖拽排序没有实时保存草稿，误刷新就丢失。
   - 盲排只是隐藏数字，缺少更中性的对比视图。

5. **视觉层次弱**
   - 标题、标签、按钮尺寸接近，缺少明确的 focal point。
   - 圆角、阴影、色板杂糅（16px 大圆角 + 100px 胶囊按钮 + 蓝色强调），风格不统一。

## Redesign 目标

- **以任务为中心**：把用户主要流程拆成「总览 → loop 监控 → 人工排序 → 配置」四大视图，用侧边栏一级导航固定。
- **状态显性化**：运行中 loop 用进度条/骨架屏/实时节点展示；等审批时突出「继续 / 停止」决策区。
- **层级清晰**：bench/sample/loop/trace 分别用不同的表面色与密度，避免卡片嵌套卡片。
- **交互细腻**：拖拽有占位反馈、排序可撤销、操作后 Toast 提示、图片 lightbox 保留。
- **统一视觉**：遵循「极简」设计系统，单色表面、12px 圆角、清晰边框、Geist 字体族。

## 页面结构

```
┌──────────────────────────────────────────────┐
│  Sidebar │  Main Content                     │
│  ────────┤                                   │
│  总览    │  ① 总览：bench 列表 + sample 卡片   │
│  运行中  │  ② loop 详情：时间线 + 控制区       │
│  排序    │  ③ 排序：双栏 / 拖拽 / 盲排        │
│  设置    │  ④ 设置：agent 配置               │
└──────────────────────────────────────────────┘
```

### 1. 总览（Overview）
- 顶部放「启动新 loop」主按钮。
- 每个 benchmark 作为一个可折叠分区，默认展开当前有运行中 loop 的 bench。
- sample 用横向卡片：左侧 target 缩略图，中间 sample 信息 + 待打分数 badge，右侧进入按钮组。
- loop 不再单独成墙，而是收在 sample 卡片内的一行「迭代记录」，hover 显示状态与最佳还原度。

### 2. loop 详情（Loop Monitor）
- 顶部面包屑 + loop 标题 + 状态灯。
- 控制区根据状态动态变化：
  - `running`：进度骨架 + 当前节点 + 剩余轮数。
  - `awaiting_review`：本轮结果摘要 + 「继续下一轮 / 停止」双按钮。
  - `error`：错误 alert 卡片 + 重试入口。
- Trace 时间线改为纵向：每轮左侧状态线，右侧图片 + 核心指标 + prompt 展开区。
- 最佳 trace 高亮，点击整行打开全屏 trace 详情（替代 modal）。

### 3. 人工排序（Scoring）
- 左栏：sample target 图 + 题目描述。
- 右栏：trace 列表，支持拖拽排序。
- 顶部工具栏：盲排开关、重置为 AI 顺序、撤销上次拖动。
- 提交后显示校准结果卡片，用进度条展示各维度权重变化。

### 4. Agent 设置（Config）
- 左侧 tabs 选择 generator / critic / summarizer。
- 右侧表单：模型 id + 系统提示词，保存后 Toast 提示。
- 增加「恢复默认」危险操作二次确认。

## 交互细节

- **Toast 通知**：启动、保存、提交排序、出错时右上角滑入，2.5s 自动消失。
- **加载状态**：页面切换与 API 调用显示骨架屏，避免白屏。
- **拖拽排序**：drag 时原位置保留灰色占位，drop 后列表平滑重排；支持键盘上下调整顺序。
- **图片查看**：所有缩略图点击放大，ESC 关闭。
- **prompt 对比**：trace 内展开 prompt，提供「与上一轮 diff」按钮，增删高亮。

## 设计系统约束

- 采用「极简」设计系统： monochrome 色板、Geist 字体、12px 圆角、1px 边框分层。
- 主色 `--primary` 用于激活态与主按钮；`--muted` 用于次级背景；`--destructive` 仅用于停止/删除。
- 阴影保持克制，仅用于浮层（toast、dropdown、lightbox）。
